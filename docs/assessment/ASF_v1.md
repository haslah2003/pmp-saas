# Assessment Simulation Framework (ASF) v1.0

## Status
Draft v1.0

## Objective
Provide a psychometric framework for generating, assessing, and adapting PMP exam questions.

## Version
ASF 1.0.0

## Metadata

- Blueprint ID
- Primary Competency
- Secondary Competency
- Decision Architecture
- Ambiguity Level
- Distractor Strength
- Decision Horizon
- Principle Alignment
- Leadership Dimension
- Systems Thinking Dimension
- Cognitive Load
- Estimated PMI Difficulty
- Quality Score
- Generation Version
- Prompt Version

## Quality Gate

Every generated question must satisfy:

- PMBOK compliance
- ECO compliance
- Scenario realism
- Single best answer
- Strong distractors
- Appropriate ambiguity
- No duplicated scenarios
- No answer-pattern bias

## Minimum Release Quality

Overall Quality Score ≥ 85
